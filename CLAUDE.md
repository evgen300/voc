@AGENTS.md

This is an online personal vocabulaty, where users can add words while learning a language.
A word is added with transcription and translation.
Also user can add word forms (cars - cars, marriage - married).
For a verb user can fill different verb times with different forms (I go - he goes)
This is a NextJS 15 project using App Router.
Styles use scss files.
Context files in src/context
Schemas in src/models/schemas

# Commands
- Dev server: `npm run dev`

# Code style
- Use 2 spaces indentation
- API routes in app/api
